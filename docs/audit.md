# Experiment audits

Portable experiment readiness audits are owned by **PsyNet**, not this workshop
repo. Use:

```bash
psynet audit init
psynet audit validate
psynet audit render
```

Install PsyNet with the optional extra (already pulled in by `psynetsk-tools`
via `psynet[audit]`):

```bash
# In ~/PsyNet
uv pip install -e '.[audit]'
```

## Contract

An audit is a portable `audit/` folder:

```text
audit/
  audit.json
  PROMPT.md
  PLAN.md
  TIMELINE.md
  REPORT.md
  artifacts/
  analyses/
  logs/
  site/          # generated by render; usually not committed
```

`audit.json` is the machine-readable manifest. The CLI packages evidence and
renders a static site; it does **not** run tests or collect artifacts for you.

Schema, CSS, and Python helpers live in PsyNet under `psynet.audit` and
`psynet/resources/audit/`. See PsyNet docs: *Experiment development → Experiment
audits*.

## Workshop coupling

Challenge attempts in PsyNetSkills do **not** use on-disk `audit.json`. The
dashboard exporter synthesizes attempt `review_sections` HTML at export time by
calling `psynet.audit` helpers (`classify_audit_evidence`, evidence/section HTML
renderers, artifact sanitization). Hugo remains shell/nav only (see merged PR
#302).

Agent workflow for standalone experiments: skill `produce-experiment-audit`.

## Migration note

The former `psynet-review-bundle` CLI, `review/` folder layout, and
`psynetsk_tools.review*` modules were removed from this repository. There is no
back-compat shim; use `psynet audit` and `audit/audit.json`.

## After PsyNet light-core

`psynet[experiment]`), re-check that workshop CI stays light:

   Dallinger / Postgres / Redis clients.
2. `uv run pytest` and `uv run psynetsk-validate` still pass.
3. Drop any temporary notes about heavy dashboard CI deps.
