# Primary color rating

Participants see red, green, and blue in turn and rate how pleasant each
color is on a 1–7 scale. The experiment includes a welcome page and a
thank-you page.

## Usage

From this directory, with PostgreSQL and Redis running:

```bash
source .venv/bin/activate
psynet test local
```

For instructions on how to run PsyNet experiments, visit the
[PsyNet documentation](https://psynetdev.gitlab.io/PsyNet/).
